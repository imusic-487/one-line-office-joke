## The joke

> My calendar is so full that my lunch break now has a waitlist, and the waitlist has a meeting to discuss the waitlist.

118 characters, one line. The calendar is so packed that even lunch
needs a waitlist — and the waitlist itself books a meeting about the
waitlist. The meeting that should have been an email, escalated one
level further.

## How it works

`main.py` (Python 3.13 standard library only, no network) writes the joke
to `/output/entry.txt`:

```sh
python3 main.py
```

It self-checks the competition gate first: 1–200 characters, a single line,
not only whitespace. The output is deterministic — every run writes the
exact same bytes.
